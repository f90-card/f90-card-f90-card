# F90 CARD: تدقيق مرحلة النقل — 2026-10-18

**حالة المرحلة:** بيئة تجهيز فقط. لا تُحوّل DNS، لا تُفعّل المورد ولا تربط دفعًا أو إيداعًا قبل المراجعة.

## تم تنفيذه في المشروع الجديد
- Supabase: `ogkipkavlywgwhtomoca` على خطة مجانية داخل المنظمة الجديدة `f90card`.
- Cloudflare Pages: `f90-card-migration` مرتبط بفرع النقل، والنشر الإنتاجي التلقائي معطّل.
- البنية الأولية: 34 جدولًا عامًا و5 جداول داخلية، المفاتيح الرئيسية والفريدة، 94 قيد قيم، 53 فهرسًا إضافيًا، 43 مفتاحًا خارجيًا (Foreign Keys).
- نسخة بيانات: 82 قسمًا، 600 منتج، 600 سجل تكلفة/تسعير منتج، 7 بنرات، 29 عملة/سعر، 15 مستوى VIP.
- سجلات الموردين الثلاثة أُدرجت **معطلة** وبلا `secret_id` أو مفاتيح أو `config` حتى لا تُرسل عمليات مزيفة أو مكررة.
- قواعد قراءة عامة (SELECT فقط) تطابق الأصل لخمسة جداول: `products`, `categories`, `banners`, `f90_rates`, `f90_vip_tiers`. لا صلاحية قراءة عامة لبيانات العملاء.
- تدقيق الجداول: RLS مفعّل، مع بقاء باقي السياسات والدوال المالية معطّلة إلى أن تستعاد وتُختبر.

## الحماية وما تبقى
1. تشغيل نسخة احتياطية مستقلة مشفّرة من مشروع المصدر قبل أي نقل معلومات شخصية أو مالية.
2. استيراد Auth كاملًا عبر المسار الرسمي لقاعدة البيانات، مع هويات Google وكلمات المرور المشفّرة، والتحقق من المعرّفات.
3. نقل دفاتر الأرصدة والطلبات والإيداعات مع التسلسل والعلاقات الصحيحة، ومطابقة الرصيد لكل مستخدم بدون تعارض حركات جديدة.
4. استرجاع الأدوار والسياسات والدوال وTriggers وحركات الموردين والـStorage؛ بعض عناصر الأصل مرتبطة بـ `pg_cron` و`pg_net` ولا يجوز تشغيلها في وجهتين في الوقت نفسه.
5. مراجعة الأمان في القاعدة الجديدة. Supabase Security Advisor سجّل سياسة RLS غير موجودة على جداول غير عامة بشكل متعمّد خلال التجهيز، وتنبيه إعداد leaked password protection؛ يجب معالجة الأول بصورة محكومة قبل التفعيل، ومراجعة الثاني.
6. مزامنة الفروقات ثم اختبار الحسابات والطلبات والشحن وعرض الأسعار، ثم اعتماد التحويل النهائي بإذن.

## خيار رسمي بديل يستحق الدراسة
تسمح Supabase بنقل **المشروع نفسه بين المنظمات** بدل تصدير واستيراد Auth. هذا يحافظ على بنية المشروع ويخفّض مخاطر اختلاف المعرّفات أو كلمات المرور، لكنه لا يُخفض تلقائيًا استهلاك Storage أو egress ولا يُلغي حدود الخطة المجانية، ويتطلب عضوية في المنظمة المستهدفة وصلاحيات مناسبة. لا تنفّذ نقل المشروع دون مراجعة أثر ربط Vercel وحدود Free.
