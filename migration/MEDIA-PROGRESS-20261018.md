# F90 CARD | نتيجة استئناف النقل الآمن بتاريخ 2026-10-18

## مرحلة الصور
- مصدر الصور العامة: Supabase الأصلي `xzqnrpycjxfbyrfaolud`، bucket `f90-images`.
- عدد الصور في جرد المصدر: **616**، مجموع الحجم: **625.99 MiB**، أكبر صورة أقل من **25 MiB**.
- تم إنشاء ملف جرد عام للصور فقط: `migration/public-media-manifest.json`، بدون ملفات الهويات أو الإيداعات.
- برنامج البناء: `migration/build-public-media.mjs`؛ يرفض مسارات `..`، الحجم غير السليم، MIME غير الصوري، أو اختلاف حجم الملف.
- تم إنشاء Cloudflare Pages إضافي باسم `f90-card-media`، مخصص للصور، ولا يحوي صفحة دفع أو حسابات.
- نشر أول: 25 صورة، حوالي 1.2 MiB؛ النتيجة **success**.
- نشر ثان: 200 صورة، حوالي 11.4 MiB؛ Cloudflare أبلغ **success** ونشر الأصول.
- فُصل **النشر التلقائي** عن مشروع الصور بعد نجاح البناء لمنع تحميل المصدر مرارًا مع تحديثات GitHub العادية.
- تم تحويل عناوين 31 صورة منتجات **في قاعدة Supabase الجديدة فقط** إلى `https://f90-card-media.pages.dev/media/f90-images/...`.
- أسعار المنتجات لم تتغير: مجموع `price` عبر 600 منتج = **1,980,023.49** عند الفحص في كلا المشروعين (هذا مجموع تقني لعمود السعر ولا يمثّل قيمة مالية موحّدة بين العملات).
- مصدر الإنتاج القديم ما زال يحتفظ بجميع الملفات الأصلية والروابط، ولم يُحذف منه شيء.

## المتبقي في الصور
- 416 صورة عامة لم تُنسخ بعد إلى Cloudflare؛ حجمها الإجمالي تقريبًا 614.6 MiB.
- 282 منتجًا في قاعدة البيانات الجديدة ما زالت روابط صوره تشير إلى Supabase القديم.
- صور المعرض `gallery` ومعلومات التصاميم في `presentation` تحتاج جردًا منفصلًا قبل استبدال الروابط.
- يجب مراقبة حصص **egress** للمشروع الأصلي قبل نقل الأصول الكبيرة دفعة واحدة، تجنبًا لتجاوز الحد المجاني قبل اكتمال النقل.
- Cloudflare R2 غير مفعّل على هذا الحساب، وأعاد API الخطأ `10042` الذي يطلب تمكين R2 عبر لوحة Cloudflare. Pages حل مناسب للصور **الثابتة**، لكنه ليس بديلًا جاهزًا لتخزين رفع صور جديدة من لوحة الإدارة؛ يلزم تصميم مسار رفع وتحديث آمن قبل التحويل.
- لا تنقل المقاطع الخاصة من `f90-identity` أو `f90-receipts` إلى Pages العام مطلقًا.
- `f90-radio` (444.39 MiB) لم يُمسّ؛ يحتاج نسخًا احتياطيًا وفحص أي اعتماد عليه قبل حذف أي ملف من الأصل.

## حالة المخاطر
- بيانات العملاء (19 حساب Auth، 20 هوية، 19 محفظة، 51 حركة دفتر، 23 طلبًا) ما زالت في المشروع الأصلي.
- الهدف الجديد فيه 3 سجلات Auth جزئية غير معتمدة و0 محافظ. **غير صالح للانتقال التجاري** حتى تتم استعادة المصادقة والبيانات المالية بصورة مطابقة.
- جداول الكتالوج ومفاتيحها وعلاقاتها أُنشئت في الهدف الجديد؛ الموردون فيه معطلون.
- لا تعديلات على `main` أو `www.f90card.online`، ولا قطع للنطاق أو إلغاء Vercel.
- RLS لا يزال يتطلب استكمال السياسات قبل تشغيل واجهة العملاء.

## بوابات النقل النهائي
1. نسخة احتياطية قابلة للاستعادة من الأصل؛ ثم استعادة Auth والهوية وكلمات المرور المشفّرة بواسطة مسار رسمي آمن بدون أسرار داخل GitHub العام.
2. استيراد المحافظ والحركات والإيداعات والطلبات والدوال والـEdge Functions ثم اختبار المصادقة والفواتير.
3. إكمال الصور الثابتة، وإنشاء مسار آمن لرفع صور جديدة عند الطلب، مع الاستغناء عن تحديث الصور المتكرر.
4. اختبار أسعار الخدمة اليدوية والمزامنة الموردية ومنع إعادة الطلب/خصم المبالغ.
5. مزامنة الدلتا، فحص الصفحات والعمليات، ثم DNS بعد موافقة جديدة صريحة.
