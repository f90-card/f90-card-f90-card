## جدول التنفيذ والتحقق

| المهمة | النتيجة | طريقة التحقق |
|---|---|---|
| إصلاح رابط API | منشور ويعمل | HTTPS GET من خارج الموقع + POST تاجر من خادم مستقل |
| مفاتيح التجار | المصادقة والصلاحيات والإلغاء مختبرة | حسابان تجريبيان منفصلان؛ مفاتيح صحيحة وخاطئة وملغاة ومحدودة |
| دليل التاجر | عربي ومنشور | اختبارات توليد الواجهة والهروب والرابط + نشر Cloudflare |
| استيراد الخدمات | 567 خدمة، 92 قسمًا وقت الاختبار | استجابة حية بالمفتاح التجريبي؛ لا تكرار معرفات ولا أسعار فارغة/غير موجبة |
| تنفيذ الطلبات | منطق الدفع والطلب مختبر معزولًا | معاملات SQL حقيقية مع ROLLBACK؛ رفض شراء HTTP برصيد صفري |
| متابعة الطلبات | التصفية بحسب المالك وكود 404 مختبران | HTTP لرقم غير مملوك + اختبار انتقالات الطلب داخل ROLLBACK |
| صور المنتجات | إصلاح 7 صور وربط صورة قسم GoMeet | ملفات أصلية مرفوعة مسبقًا، ذات provenance موثق، مع تحديث image_url فقط |
| ترتيب الأقسام | الحفاظ على الموجود واسترجاع اليدوي المخفي | 92 قسمًا في API؛ لم تُحذف أو تُدمج منتجات مختلفة |
| سلامة الأسعار | لم تنفّذ هذه المهمة تحديث أسعار أو هوامش أو عملات | مراجعة SQL: تحديثات الصور فقط، واختبارات الأموال أُلغيت |
| اختبارات الأمان | رفض المفاتيح والصلاحيات والرصيد؛ لا حقول أسرار في كتالوج الفحص | HTTP حي + اختبارات بوابة معزولة + فحص الاستجابة |
| نشر Cloudflare | نجح نشر البوابة والدليل | قراءة canonical deployment على الدومين الرسمي |

### قبول HTTP حي على /api/v1
- GET تعريف الواجهة: 200، JSON، العنوان الصحيح.
- services: 200، 567 خدمة.
- categories: 200، 92 قسمًا.
- balance: 200، USD، رصيد الحساب التجريبي صفر.
- quote لخدمة يدوية: 200، إجمالي 3.4 دولار في الاختبار؛ قراءة فقط.
- مفتاح ملغى: 401 / F90_AUTH.
- مفتاح خاطئ: 401 / F90_AUTH.
- مفتاح لا يملك صلاحية الرصيد: 403 / F90_FORBIDDEN.
- محاولة عملية إدارة بمفتاح تاجر: 403.
- checkout برصيد تجريبي صفري: 402 / F90_INSUFFICIENT_BALANCE.
- status لرقم غير موجود أو غير مملوك: 404 / F90_NOT_FOUND.
- فحص استجابة الخدمات: صفر معرفات مكررة، صفر أسعار مفقودة/غير موجبة، وعدم وجود مفاتيح حقول token_hash/secret_id/api_token/api_key/service_role/provider_id/provider_service/endpoint.
- خدمتا جوال وأوريدو اليدويتان ظهرتا بعد إصلاح الفلتر.
- الفحص السابق لـ /api/merchant ناجح كذلك؛ لم يُقطع التوافق القديم.

### اختبارات مالية حقيقية مع إلغاء كامل للمعاملة
نفّذت الدوال الفعلية على هوية ومنتج مؤقتين غير مرئيين للجلسات الأخرى، ثم ROLLBACK:
- حساب السعر على الخادم.
- رفض إجمالي مختلف وحقول حساب ناقصة.
- مرجع الشراء نفسه يعيد طلبًا واحدًا وخصمًا واحدًا وحجز مخزون واحدًا.
- مرجع نفسه مع بيانات مستلم مختلفة يُرفض.
- فشل الطلب يرد الرصيد مرة واحدة؛ تكرار الفشل لا يضاعف الرد ولا استعادة المخزون.
- رفض الرصيد غير الكافي.
- لم يُستدعَ أي مورد، ولم تُحفظ أي معاملة اختبار أو خصم أو استرداد.

أُنشئ حسابان تقنيان تجريبيان برصيد صفر لاختبار HTTP؛ لم تتولد لهما طلبات أو قيود مالية. حُذفا مع مفاتيحهما وسجلات استخدامهما بعد التحقق. عادت المفاتيح الأصلية إلى 14 منها واحد نشط و13 معطلًا. لم تُقرأ أسرار مفاتيح العملاء ولم يُفعّل أي مفتاح ملغى.

## حدود القبول المفتوحة
1. لا يوجد اختبار شراء مدفوع فعلي عبر ياسين؛ لم يُستخدم مال العملاء أو تُنشأ طلبات مورد تجريبية حقيقية. اختبارات adapter والشراء المعزولة لا تعني تنفيذ شحنة خارجية.
2. لم يُختبر متجر تجاري خارجي محدد ببرنامج الربط الخاص به. اختُبر عميل HTTP خادمي تجريبي. أي متجر يتطلب بروتوكول SMM أو Yassen مختلفًا يحتاج مطابقة عقده، لا مجرد لصق الرابط.
3. GET يعرض معلومات الواجهة فقط؛ العمليات تستخدم POST JSON وترويسة x-f90-key. لم تُضف profile/check أو webhooks أو مصادقة key في URL. العمليات الموثقة: categories/services/service/balance/quote/checkout/add/status/history.
4. اختبار CORS OPTIONS نجح في الاختبارات المعزولة؛ فحصه الحي من GitHub Runner ما زال queued. فحص المتصفح المرئي عبر TinyFish لم يبدأ لنفاد رصيده. لا ادعاء اختبار دخول/إيداع حي بالمتصفح في هذه الجلسة.
5. بقيت 11 صورة بلا رابط: عشر خدمات معطلة، وخدمة فعالة واحدة «شامنا 12 شهر» تحتاج مطابقة هوية التطبيق/المصدر بدقة. لم توضع صور تخمينية. من الخدمات المعطلة أسماء مبهمة مثل WWWW وzzzz وKkkkk وGgggg، وريد باكيج وخدمات تصميم وEpay وZain TV.
6. يوجد ارتباط مورد مكرر لخدمة إكزينا نشطة ونسخة SHIPMENT XENA LIVE معطلة. لا يظهر تكرار في API؛ لم تُحذف بيانات أي نسخة أو طلب تاريخي.
7. بقيت تحذيرات Supabase السابقة في فحص الأمان؛ هذا العمل ليس شهادة اختراق شاملة.
8. تغيّرت البصمة العامة للأسعار أثناء نافذة العمل بالتزامن مع عمل المزامنة/التعديلات الأخرى في المتجر الحي؛ لذلك لا أدعي ثبات جميع الأسعار طوال الجلسة. لم يُنفّذ هذا العمل أي SQL لتغيير سعر أو هامش أو عملة، ولم تُسترجع أسعار قديمة أو تُوقف المزامنة الحالية.

## تعليمات جاهزة للتاجر

عنوان الاتصال:
https://www.f90card.online/api/v1

من حساب تاجر نشط وموثّق، افتح «مفتاح ربط المتاجر» وأنشئ المفتاح وانسخه عند ظهوره. إصدار مفتاح بديل يلغي السابق. احفظه على خادم متجرك فقط في F90_API_KEY؛ لا ترسله إلى المتصفح أو في الرابط.

أرسل POST بصيغة JSON:
Content-Type: application/json
x-f90-key: مفتاحك_السري

ابدأ بالقراءة:
{"action":"services"}
{"action":"categories"}
{"action":"balance"}

احفظ service معرّفًا ثابتًا للمنتج، وحدّث السجل نفسه عند المزامنة. استخدم image_url وcategory وmin/max وquantity_step وunit_quantity وfields كما تعيدها الواجهة. لا تعتبر فشل الاتصال كتالوجًا فارغًا.

قبل الشراء:
{"action":"quote","product_id":"معرف_الخدمة","quantity":1000}

للشراء:
{"action":"checkout","product_id":"معرف_الخدمة","quantity":1000,"fields":{"account_id":"معرف_المستلم"},"idempotency_key":"مرجع_فريد_محفوظ_مسبقًا","expected_total_usd":الإجمالي_المعاد_من_quote}

حقول fields تختلف حسب الخدمة. احفظ رقم الطلب من data.id، وتابعه:
{"action":"status","order":"رقم_الطلب"}

عند فقد الرد، أعد إرسال المرجع نفسه والبيانات نفسها. لا تنشئ مرجع دفع جديدًا تلقائيًا. الأسعار والرصيد في API بالدولار، والتسعير النهائي دائمًا من quote والخادم.
