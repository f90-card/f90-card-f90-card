# مركز تحكم F90 CARD

## الروابط
- واجهة المدير: /ops.html
- رابط داخل لوحة الإدارة: /admin.html
- Supabase Edge Function: f90-ops-control
- حساب المشروع: ogkipkavlywgwhtomoca

## الأمان
- تتطلب كل الطلبات جلسة Supabase مع تحقق session_id وصلاحية manager من f90_user_roles.
- تتطلب التغييرات إكمال التحقق الثنائي AAL2 وتفعيل عامل TOTP.
- لا يطّلع عميل على أدوات أو سجلات مدير آخر.
- لا يعرض النظام مفاتيح الموردين أو API أو كلمات مرور العملاء.

## المكونات
1. المراقبة: إحصاءات الطلبات والإيداعات والإشعارات والموردين، وحالة المجدول من f90_ops_cron_health.
2. الأمان: عرض الحسابات وأحدث نشاط IP والجهاز؛ إيقاف ساعة/يوم/أسبوع/شهر أو حظر أو استعادة، مع سبب وتدقيق. إعادة تعيين كلمة المرور عبر البريد المسجّل فقط.
3. مختبر API: اختبار قراءة كتالوج دون إحداث عملية شراء أو خصم رصيد، وإظهار استخدامات المفاتيح دون كشف أسرارها.
4. الطوارئ: ف90_ops_flags والقواعد f90_ops_block_new_orders وf90_ops_block_new_deposits وf90_ops_merchant_gate_sync. يوقف إدخالات جديدة ولا يلغي طلبات قائمة.
5. الأرباح: حساب تقديري للطلبات المكتملة من الإجمالي بعد الاسترداد والتكلفة المسجّلة. لا يعادل محاسبة كاملة ولا يشمل كل المصاريف والعمولات.
6. النسخ: إنشاء نسخ تشغيلية انتقائية داخل حاوية تخزين خاصة باسم f90-ops-private-backups، وتسجيل SHA-256 والحجم وإمكانية اختبار سلامة النسخة من الواجهة. لا تشمل كل جداول أو ملفات النظام، ولا تنفّذ استعادة تلقائية.

## حدود مهمة
- ليست هناك نسخة تشغيلية حتى يضغط مدير مؤهّل على زر إنشاء نسخة وينجح الرفع.
- فحص API يختبر القراءة الداخلية فقط؛ اختبار طلب التاجر الخارجي الحقيقي منفصل.
- بيانات العميل الجغرافية تقريبية وليست GPS، ويجب الاحتفاظ بالإشعار عنها في سياسة الخصوصية.
- يتطلب فحص فعلي بعد تسجيل الدخول صلاحية المدير وتفعيل MFA.
- لا تُستعاد أرصدة أو معاملات مباشرة من واجهة النسخ؛ الاستعادة تحتاج خطة ومراجعة مالية على نسخة اختبار أولًا.
