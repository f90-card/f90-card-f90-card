# دليل ربط التجار - أف تسعين كارد

عنوان الخدمة: `https://xzqnrpycjxfbyrfaolud.supabase.co/functions/v1/f90-platform`

أنشئ حسابًا من المتجر، واطلب من الإدارة تفعيل صلاحية تاجر. أضف رصيدًا وانتظر اعتماد الإيداع؛ الطلبات تُخصم من محفظة حسابك بالدولار. أنشئ مفتاحًا من صفحة «وكلاؤنا والمبرمجون»، أو استلمه من المدير. يظهر المفتاح كاملًا مرة واحدة فقط.

احفظ المفتاح في متغير بيئة على خادم متجرك باسم `F90_API_KEY`. لا تضعه في JavaScript المتصفح أو تطبيق العميل أو سجلات الطلبات. إلغاء المفتاح أو إيقاف الحساب يمنع الطلبات التالية.

## الطلب والاستجابة

أرسل `POST` مع `Content-Type: application/json` و`x-f90-key: مفتاحك`. يمكن إرسال نموذج `application/x-www-form-urlencoded` أيضًا. لا يُطلب مفتاح Supabase من التاجر.

النجاح: `{ "data": ... }`. الخطأ: `{ "error": { "code": "...", "message": "..." } }` مع رمز HTTP مناسب. هذا بروتوكول أف تسعين؛ قد يحتاج متجر يستخدم بروتوكولًا آخر إلى محوّل للاستجابات.

| العملية | جسم الطلب | بيانات النجاح |
| --- | --- | --- |
| الخدمات | `{"action":"services"}` | مصفوفة خدمات فعّالة مع المعرّف والأسعار وحدود الكمية وطريقة التنفيذ |
| الرصيد | `{"action":"balance"}` | `balance` و`currency: "USD"` |
| تسعير قبل الشراء | `{"action":"quote","product_id":"UUID","quantity":1000}` | `subtotal_usd` و`discount_usd` و`total_usd` |
| شراء | `{"action":"add","service":"UUID","quantity":1000,"link":"معرف العميل","idempotency_key":"your-order-10001"}` | الطلب، بما فيه `id` و`order_number` و`total_usd` و`status` |
| حالة الطلب | `{"action":"status","order":"UUID"}` | `order` و`events` |
| سجل الطلبات | `{"action":"history","kind":"orders","offset":0}` | `items` و`count`؛ ٥٠ سجلًا لكل صفحة |

`service` هو UUID منتج أف تسعين من قائمة الخدمات، وليس رقم الخدمة لدى المورّد الخارجي. إذا كانت الخدمة تتطلب حقولًا إضافية، أرسل `fields` ككائن مثل `{"account_id":"12345","server":"asia"}` بدل `link`. راجع الحقول المطلوبة في بيانات الخدمة.

سعر الخدمة `rate` أو `price_usd` يخص `unit_quantity` وحدة؛ مثل ١٠٠٠ أو مليون. تسعير الباقة الثابتة يخص الباقة كلها. اعتمد `quote` أو `total_usd` النهائي عند تسوية فاتورتك؛ يمكن أن يتأثر بسعر التاجر ومستوى التميّز وشرائح الكمية. المحفظة والخصم دائمًا بالدولار.

يمكن استخدام `checkout` بدل `add` مع `product_id` و`fields` و`expected_total_usd` لضمان موافقة العميل على آخر سعر. يرفض الخادم سعرًا قديمًا قبل الخصم.

## منع تكرار الدفع

أنشئ `idempotency_key` مرة واحدة لكل طلب في متجرك، واحفظه قبل أول اتصال. طوله من ٨ إلى ١٦٠ محرفًا. أعد استخدام **نفس المفتاح ونفس البيانات** إذا انقطع الاتصال. يرجع الطلب السابق دون خصم ثانٍ حتى لو تغيّر سعر المنتج بعد إنشائه. أما إعادة استخدام المفتاح مع منتج أو بيانات عميل مختلفة فترجع خطأ `F90_IDEMPOTENCY_CONFLICT` (409). لا تُنشئ مفتاحًا جديدًا عند إعادة الاتصال، ولا تعِد استخدامه لشراء مختلف. احفظ `data.id` لمتابعة الطلب.

لا تعني خسارة الاستجابة أن الطلب فشل. افحص الحالة أو أعد طلب الشراء بمفتاحه الأصلي. حالة `review` تحتاج مراجعة الإدارة؛ لا ترسل شراء بديلًا تلقائيًا.

## حالات التنفيذ

| القيمة | المعنى |
| --- | --- |
| `pending` | طلب يدوي ينتظر الإدارة |
| `queued` | طلب آلي في طابور الإرسال |
| `submitting` | إرسال للمورّد؛ لا إعادة إرسال من التاجر |
| `processing` | قيد التنفيذ |
| `completed` | اكتمل |
| `partial` | تنفيذ جزئي؛ راجع `refunded_usd` |
| `review` | نتيجة تحتاج مراجعة الإدارة |
| `failed` | فشل مؤكد مع الاسترداد المسجل |
| `refunded` | استُرد المبلغ |

تتم متابعة الطلبات الآلية على الخادم كل دقيقة. يمكن الاستعلام كل ٣٠ إلى ٦٠ ثانية؛ الحد الافتراضي ٦٠ طلبًا في الدقيقة لكل مفتاح. لا يوجد إشعار Webhook للتاجر في هذه النسخة؛ استخدم الاستعلام عن الحالة.

## أخطاء متوقعة

| HTTP | الرمز المعتاد | الإجراء |
| --- | --- | --- |
| ٤٠١ | `F90_AUTH` | تحقق من المفتاح وصلاحيته |
| ٤٠٢ | `F90_INSUFFICIENT_BALANCE` | أضف رصيدًا وانتظر اعتماد الإدارة |
| ٤٠٣ | `F90_FORBIDDEN` | الحساب موقوف أو ليس تاجرًا أو الصلاحية ناقصة |
| ٤٠٠ | `F90_FIELDS` / `F90_QUANTITY` | أكمل الحقول واحترم حدود وخطوة الكمية |
| ٤٠٩ | `F90_IDEMPOTENCY_CONFLICT` | المرجع مرتبط بعملية سابقة مختلفة؛ افحص الطلب القديم ولا تنشئ شراءً آخر تلقائيًا |\n| ٤٠٣ | `F90_VERIFICATION_REQUIRED` | أكمل توثيق الحساب قبل الشراء أو الإيداع |\n| ٤٠٩ | `F90_REFILLING` | الخدمة غير متاحة حاليًا |
| ٤٠٩ | `F90_PRICE_CHANGED` | حدّث عرض السعر وأعد التأكيد |
| ٤٢٩ | `F90_LIMIT` | انتظر قبل إعادة المحاولة |

المثال `reseller-example.mjs` مخصص لخادم Node.js ويعيد المحاولة فقط عند طلبك بالمفتاح الأصلي؛ لا يجري أي شراء عند استيراده.
