# ربط ياسين كارد

## الحالة الفعلية (13 أكتوبر 2026)

- مضيف API العامل: `https://api.yassen-card.com`، مع ترويسة `api-token`. صفحة التوثيق تعرض `https://yassen-card.com/` بوصفه Base URL، لكنه أعاد HTML عند فحص مساري الخدمات والحساب؛ مضيف API أعاد JSON صالحًا.
- فحص الحساب والخدمات كان للقراءة فقط. جرى حفظ المفتاح في Supabase Vault، ولا يوجد في ملفات الموقع أو المستودع.
- الاستجابة: 783 خدمة، منها 593 متاحة بسعر، و580 خدمة استوفت حدود كمية المتجر وحُفظت كمسودات مخفية. 190 غير متاحة و13 تحتاج معالجة حدود كمية غير مدعومة. لا يُنشئ الاستيراد طلبات شراء.
- هامش التسعير الحالي 20% على سعر USD للمورّد. افحص الأسعار والأقسام والحقول قبل النشر. رصيد الحساب عند الفحص 0.034، والطلبات الآلية معطلة.
- 245 خدمة صغيرة السعر تُعرض لكل ألف أو مليون وحدة مع بقاء حدود الكمية الأصلية، حتى لا يُعرض سعر 0.00 بسبب دقة عمود السعر ذات المنزلتين.
- المورّدان السابقان مؤرشفان، ومفاتيحهما محذوفة من الخزنة؛ تبقى روابط المنتجات وسجلات الطلبات للتاريخ، ولا تظهر خدماتهما في الكتالوج.

## إدارة الموردين

من «الإدارة ← مصادر خدماتك» يمكنك فحص الرصيد والخدمات، واستيراد دفعات أو جميع الخدمات كمسودات، ومعاينة مزامنة الأسعار قبل تأكيدها، وتعديل الاسم والرابط والهامش والمفتاح، وإضافة مورد ببروتوكول مدعوم، وإيقافه أو حذفه من التشغيل. حذف المورد يحتفظ بالطلبات المرتبطة ويحذف سر الاتصال. تفعيل عرض الخدمات منفصل عن تفعيل إرسال الطلبات الآلية.

## خانات لوحة ياسين كارد الظاهرة في الصورة

| الخانة | الإعداد المطلوب |
| --- | --- |
| API TOKEN | المفتاح الحالي محفوظ على الخادم؛ لا حاجة لكتابته هنا مرة ثانية. بعد تدويره حدّثه من إعدادات المورد في F90. |
| IPS | لا تُدخل IP ثابتًا عشوائيًا. وظائف Supabase Edge لا توفر IP خروج ثابتًا للاعتماد عليه في قائمة السماح. إذا كانت قائمة IPS إلزامية في حسابك، يلزم بوابة خروج ثابتة قبل تفعيل القيد. |
| webhook url | اتركها فارغة حاليًا. التوثيق المنشور يشرح قراءة حالة الطلب عبر `/client/api/check` ولا يحدد حمولة webhook أو توقيعه؛ لا يمكن تأمين مستقبِل موثوق من دون ذلك. |

مسارات API موثقة في [صفحة ياسين كارد](https://api.yassen-card.com/api-docs). طلب الإنشاء يستخدم `order_uuid` لتجنب التكرار؛ لم يُنفذ طلب شراء تجريبي، وينبغي التحقق من حقول منتج مختار ورصيد كافٍ قبل تفعيل الطلب الآلي.
