# ربط مورد F90 CARD بمفتاح تاجر

اسما المحولين المنشورين:
- **F90 Card API (api-token / GET)** لقراءة المنتجات والرصيد والحالة.
- **F90 Merchant API v1 (POST / JSON / x-f90-key)** للربط الأصلي.
نفس المفتاح صالح للطريقتين؛ إنشاء المفتاح يعرض اختيار اختبار البروتوكول.
القيمة الداخلية f90_merchant مستقلة عن f90 الذي يعني موردًا يدويًا بلا API.
الربط HTTPS/JSON وفق عقد F90؛ مختلف عن ياسين وSMM وBearer.

| الخانة | القيمة للتجربة |
|---|---|
| الاسم | F90 CARD — تجربة حساب التاجر |
| عنوان الاتصال | https://www.f90card.online/api/v1 |
| البروتوكول | F90 Card API (api-token / GET) أو F90 Merchant API v1 (POST / JSON / x-f90-key) |
| العملة | USD |
| المفتاح | مفتاح حساب تاجر نشط وموثق، بصلاحيات catalog وbalance وorders |
| الطلبات الآلية عند الربط بنفس المتجر | متوقفة؛ يمنعها الخادم والمحول |

احفظ المورد ثم استخدم «فحص الاتصال» أو «رصيد المورد» و«استعراض واستيراد الخدمات».
الحفظ والفحص لا ينشئان طلبًا مدفوعًا. الاستيراد اختياري ويحفظ مسودات مخفية؛ لا تنشر نسخ تجربة المتجر نفسه.
لم تضف هذه المهمة موردًا دائمًا أو تنسخ المنتجات تلقائيًا، ولم تعدل ياسين أو الأسعار أو الأرصدة.

## سلوك المحول
- POST JSON مع x-f90-key في المحول الأصلي. GET مع api-token إلى /client/api/products و/client/api/profile و/client/api/check في محول القراءة. الشراء POST فقط؛ لا يوجد شراء عبر GET.
- لا يُرسل المفتاح في الرابط.
- services + categories وbalance وstatus بعقد data.order.
- لمتجر مستقل: checkout بمعرف الخدمة والحقول الأصلية والتكلفة المتوقعة ومرجع الطلب المحلي الثابت idempotency_key.
- يمنع تحويلات HTTP وتسريب رسائل المورد الخام، ويحافظ على تمييز نتيجة الشراء غير المؤكدة.
- الاستيراد يحفظ الأسماء والصور والحقول ونوع التسعير والخطوة والوحدة. معرّف القسم الموجود يُطابق مباشرة، والبقية تخضع لمراجعة التصنيف المعتادة.
- الاستيراد المتكرر يتجاوز ربط provider/service الموجود دون نسخة جديدة.
- برنامج المتجر الخارجي يحتاج دعم عقد F90 أو إضافة محول وفق دليل التاجر؛ مجرد وجود خانة رابط ومفتاح لا يثبت التوافق.

## التحقق المنفذ 21 أكتوبر 2026
- 106 اختبارات CJS و155 اختبار MJS ناجحة.
- اختبارات الترويسة والكتالوج والوحدة والحقول والرصيد وفك الحالة ومرجع الشراء الثابت ومنع الطلب الذاتي والأخطاء وشاشة إضافة المورد ناجحة.
- استدعاء حي لكل من محولي POST وGET من خادم مستقل بمفتاح معزول: 567 خدمة لكل طريقة، أسماء أقسام عربية وصور وحقول ورصيد 0 USD. رُفض المفتاح الخاطئ. العدد لقطة زمنية.
- قيد قاعدة البيانات يقبل f90_merchant؛ اختُبر بإدخال داخل معاملة أُلغيت.
- حُذف الحساب والمفتاح التقنيان بعد التأكد من صفر رصيد وعدم وجود طلبات أو قيود مالية.
- f90-platform إصدار 27. لم يُنفذ شراء مدفوع أو إرسال طلب إلى ياسين في هذا التغيير.

تمت المحافظة على تحديثات GET والدليل وإنشاء المفتاح الأحدث، وإزالة معالج change مكرر كان يعيد تفعيل مربع الطلبات الآلية في واجهة الربط الذاتي رغم حماية الخادم.
