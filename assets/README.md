# صور أف تسعين كارد

مجلد sections يضم صور الأقسام والإعلان التي قدمها صاحب المتجر، وتظهر في منتقي الهوية داخل الإدارة. يمكن رفع بديل أو إزالة صورة العنصر أو تكراره.

f90-logo.png هو الشعار الحالي. icons يحتوي نسختين مصغرتين بالمقاسين ١٩٢ و٥١٢ للتثبيت. يمكن استخدام GIF للشعار وصورة PNG مستقلة للتطبيق.

fonts وvendor يحتويان خط التقرير العربي وأداة تصدير PDF وتراخيصهما.
